What PhishGuard checks

        
Every message is read for four kinds of warning sign. Each one found becomes a fact for the rule engine.

        
    
          
  • Who sent itForged or lookalike sender addresses, free webmail posing as a company, replies redirected elsewhere.
    • 
          
  • Where links really goLookalike domains, link shorteners, raw IP addresses, links whose text and target differ.
    • 
          
  • How it pressures youDeadlines, threats of suspension, prizes, requests for secrecy.
    • 
          
  • What it asks forPasswords and codes, payments and gift cards, card or ID details, risky attachments.
    •
